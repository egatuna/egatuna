## About Me

I'm a junior at Purdue's Mitchell E. Daniels, Jr. School of Business, studying Integrated Business and Engineering with a concentration in AI and Data Analytics. I learn best by building things and shipping them. I run **SynthLab**, an Indiana LLC I founded, where I build websites, automation pipelines, and AI-assisted tools for small businesses. I also designed, built, and launched the public website for my employer, a healthcare staffing agency. As a Purdue VIP researcher I studied proxy discrimination in AI resume-screening tools: how automated hiring can work against applicants through variables that stand in for protected traits. I can build these systems and audit them, and I bring both to analytics and product work.

**Currently working on:** the student-facing interface for an AI lab teaching assistant with Purdue's [co_TA VIP project](https://github.com/egatuna/co_TA), on the Human Interface team.

### local-agent: Self-Verifying On-Device Coding Agent
A coding agent that runs a small open model locally through Ollama on an 8 GB laptop. It never trusts the model's "done" claim: the harness re-runs the tests itself before a run can succeed, catches loops, and can hand failed tasks to Claude Code. In my benchmark, the 2B model plus escalation reached a verified-correct result in 2:45 where a 4B model alone took 14:18.
<br>
**Skills:** Python · Ollama · Agent Design · Verification · Benchmarking
<br>
[![Repository](https://img.shields.io/badge/Repository-1F6F78?style=for-the-badge&logo=github&logoColor=white)](https://github.com/egatuna/local-agent)
